# A small research procedure

1. Define one question and the expected output.
2. Find an original public source and record its date.
3. Distinguish announced plans from completed releases.
4. Write a short brief and save it in the dedicated workspace.
5. Open the actual file and check the length, source and claims.
6. Preserve the original if a correction is needed. Save a reviewed version separately.

The handoff is internal and marked for review. It does not activate another assistant or authorise publication.
