# Check the result, not just the reply

The first Luna draft was too long and used secondary sources. We preserved it, gave a targeted correction and saved a new version rather than hiding the original result.

For a portfolio build, a missing navigation file should fail the strict build. Check the filename and path before publishing. A successful local build is not evidence that GitHub Pages is live.

Before sharing, review every staged file for private information. Never publish credentials, raw runtime configuration or unrelated personal material.
